
# Network-Tools-Batch
Ein einfaches Batch-Skript zur schnellen Überprüfung der Netzwerkverbindung.

**Funktionen:**
- Liest das Standardgateway (Router) über `ipconfig` aus.
- Prüft die aktive Internetverbindung durch einen Ping an den Google-DNS-Server (8.8.8.8).
- Gibt eine klare Rückmeldung (OK / FEHLER) basierend auf dem Errorlevel.
